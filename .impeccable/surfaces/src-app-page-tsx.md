# Surface: `/` — Mel Beaute & Aesthetic marketing home

## Mode
Persuade

## Audience / job / action
KL/JB clients deciding whether to book aesthetic treatments; need trust + clear catalog; primary action is WhatsApp booking.

## Direction contract

THESIS: A calm spa-suite landing that puts Mel Beaute’s gold MB mark and one WhatsApp booking path first—refusing the dense flyer-grid / multi-card clinic homepage template.

OWN-WORLD: Dawn-cyclorama blush: champagne cream ground rising into soft rose atmosphere; champagne-gold MB monogram and hairlines; deep berry ink for prices; floral silhouette ornament only at edges. Display serif for brand, light script for intimacy, clean humanist sans for lists. No purple glow, no terracotta cream cliché, no dashboard cards in the hero.

STORY: Visitor recognizes a premium yet approachable KL aesthetic clinic, believes the 4.9★ care from real reviews, and WhatsApps about a named treatment.

FIRST VIEWPORT: Full-bleed atmospheric plane (rose→cream horizon bands). Centered gold MB logo at hero scale, clinic name beneath, one headline (“Your skin, our priority”), one supporting line, one CTA group (WhatsApp primary + View treatments). No stats strip, no schedule, no promo chips over the hero.

FORM: Hotel spa suite / marble powder room (#4 of grounded list; seed key abe36a79). Raises: cyclorama horizon banding for page atmosphere; parametric CSS token seed so palette/motion stay locked; specimen-scale contrast for the MB mark.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
